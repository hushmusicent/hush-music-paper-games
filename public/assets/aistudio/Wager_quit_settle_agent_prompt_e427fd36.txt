Settle a wagered PvP game when a player quits mid-game. Paste this into the AI Studio agent chat for the Hush Music Paper Games project.

---

The problem: in a wagered online PvP game, each player's wager is held at game start (OnlinePoints.add -wager, wagerHeld flag), but the wager only settles in handleFinish() in src/views/GameActiveView.tsx. Every quit path — the in-game Quit button / "Yes, quit" modal, "All games" from the results screen, handleQuitFromFinished() — calls onQuit() and leaves the room with no settle at all. So if someone quits mid-game, both wagers stay held forever: the quitter loses theirs, the player left behind loses theirs too, nobody gets the pot, and no win/loss is recorded.

Where it is: src/views/GameActiveView.tsx — the wager hold effect, handleFinish() (the only settle), handleQuitFromFinished(), and the quit modal that calls onQuit(). src/App.tsx — quitGame() (leaves the room/voice). src/utils/net.ts holds the room doc (RoomDoc) and the push/listen helpers.

### The rule (same as the other hubs)

Quitting mid-game is a forfeit: the player who quits loses, the player left in the room wins and takes the pot.

1. When a player quits a wagered online game while it is still in progress (status 'playing', game not finished), record the forfeit on the room doc before leaving — for example a `forfeit` map on the room with one entry per player uid (forfeit/<uid>: true) — and mark their own side settled (wagerSettled/<uid>: true) so their held wager is never refunded. Record their loss (OnlinePoints.record 'l') the same way handleFinish does for a loss.
2. The player still in the room sees the opponent's forfeit on the room doc and settles as the winner, exactly like a normal win: one combined points write (the flat 200 ⭐ PvP win + the 2x wager pot), the win record, and wagerSettled/<uid>: true. Reuse the existing settle guards (room.wagerSettled flag + the settle key ref) so a forfeit win can never pay twice, and so it can never double-pay if the game also finishes normally.
3. If the quitter taps quit from the results screen AFTER the game already finished, change nothing — that game already settled in handleFinish.
4. If both players quit (nobody left in the room to claim the pot), just mark both sides settled with no payout — do not refund held wagers.

### Details
